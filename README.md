# CMWP — два направления портфолио

Один React + Vite проект, два независимых оформления:
- `/editorial/` — портрет и редакционная типографика
- `/architecture/` — типографика, графика территорий, выбор проектов

`npm install`, `npm run dev` (порт 5174), `npm run build`.
Одна сборка `dist` содержит обе страницы. При статическом размещении требуется SPA fallback на index.html.

Общие материалы и компоненты находятся в src/main.jsx; оформление — src/style.css.
Нет сервера, форм и внешних интеграций. Контактные ссылки открывают почту или телефон.

Источник сведений и портрета: https://www.cmwp.ru/team/5792/
Портрет: https://www.cmwp.ru/upload/iblock/443/2npyxzjgpon0racgml3ojkebrpg1d2ff.png
Графика территорий — авторские абстрактные SVG, не реальные планы объектов.
Референсы: https://dennissnellenberg.com/ и https://www.nathansmith.design/

## Вторая версия: фотогалерея

`/architecture/` теперь содержит самостоятельную галерею в src/Gallery.jsx и src/gallery.css. При наведении или фокусе фотография работы становится фоном страницы. По клику открывается диалог; закрытие — кнопкой, Esc или по подложке. На телефоне — одноколоночная галерея с открытием по нажатию.

Фотографии показывают территории, не результаты консалтинговых работ:
- Шерегеш: https://www.aviasales.ru/psgr/article/skolko-stoit-sheregesh
- Курилы: https://vasta-expeditions.ru/info/kurilskie-ostrova
- Истра: https://www.rbc.ru/life/news/62c6dfc79a7947561fd2ca65
- Вьетнам: https://www.ivivu.com/blog/2025/10/top-10-khach-san-resort-5-sao-tot-nhat-viet-nam-2025/

Для публикации заменить изображения на согласованный фотоархив заказчика либо лицензированные материалы.

### Обновление: слайдеры и портрет
- `Interactions.jsx` — горизонтальные слайдеры, магнитные кнопки с плавной заливкой, округлая изменяющаяся граница футера.
- `news.json` — все 30 заголовков, дат и исходных ссылок из раздела новостей профиля CMWP; карточки содержат только заголовок, дату и название источника.
- Во втором варианте портрет заполняет первый экран и уменьшается при прокрутке в карточку справа в верхнем блоке; при наведении увеличивается и выравнивается.
- Снижение движения учитывает системное prefers-reduced-motion.

Переход футера: светлая SVG-плоскость выгибается вниз поверх темного футера и выпрямляется при прокрутке. В первом варианте одна круглая кнопка «Связаться»: она следует за окном, затем занимает зарезервированное место в футере и отлипает при обратной прокрутке. Во втором варианте уменьшенный портрет привязан к позиции в документе и уходит со страницей.

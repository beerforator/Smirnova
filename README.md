# CMWP — два направления портфолио

Один React + Vite проект, два независимых оформления:
- `/editorial/` — портрет и редакционная типографика
- `/architecture/` — типографика, графика территорий, выбор проектов

`npm install`, `npm run dev` (порт 5174), `npm run build`.
Одна сборка `dist` содержит обе страницы. После Vite скрипт `scripts/build-routes.mjs` создает `dist/editorial/index.html` и `dist/architecture/index.html`, поэтому прямые ссылки и обновление страницы работают на статическом хостинге без SPA fallback. Скрипты, стили и изображения остаются общими.

Render Static Site: Build Command — `npm ci && npm run build`, Publish Directory — `dist` (относительно корня проекта `porfolio`). После обновления исходников выполнить новый deploy. Ссылки: `/editorial/` и `/architecture/`.

Общие материалы и компоненты находятся в src/main.jsx; оформление — src/style.css.
Нет сервера, форм и внешних интеграций. Контактные ссылки открывают почту или телефон.

## Вторая версия: фотогалерея

`/architecture/` теперь содержит самостоятельную галерею в src/Gallery.jsx и src/gallery.css. При наведении или фокусе фотография работы становится фоном страницы. По клику открывается диалог; закрытие — кнопкой, Esc или по подложке. На телефоне — одноколоночная галерея с открытием по нажатию.

Фотографии показывают территории, не результаты консалтинговых работ:

Для публикации заменить изображения на согласованный фотоархив заказчика либо лицензированные материалы.

### Обновление: слайдеры и портрет
- `Interactions.jsx` — горизонтальные слайдеры, магнитные кнопки с плавной заливкой, округлая изменяющаяся граница футера.
- `news.json` — все 30 заголовков, дат и исходных ссылок из раздела новостей профиля CMWP; карточки содержат только заголовок, дату и название источника.
- Во втором варианте портрет заполняет первый экран и уменьшается при прокрутке в карточку справа в верхнем блоке; при наведении увеличивается и выравнивается.
- Снижение движения учитывает системное prefers-reduced-motion.

Переход футера: светлая SVG-плоскость выгибается вниз поверх темного футера и выпрямляется при прокрутке. В первом варианте одна круглая кнопка «Связаться»: она следует за окном, затем занимает зарезервированное место в футере и отлипает при обратной прокрутке. Во втором варианте уменьшенный портрет привязан к позиции в документе и уходит со страницей.

### Вступление второго макета
ФИО отображается единственным h1 и перемещается отдельно от изображения. Первые 36% высоты экрана прокрутки отведены опусканию имени и легкому уменьшению портрета при полноэкранном фоне. Затем за следующие 82% высоты экрана фон, карточка и имя плавно занимают свои места. Переход обратим; после завершения элементы прокручиваются со страницей. Системное снижение движения пропускает вступление.

## Третий вариант — /dossier/

Независимая композиция в `src/Dossier.jsx` и `src/dossier.css`: графит, молочный и серо-зеленый. На десктопе портрет остается в боковой колонке при прокрутке основного содержания; перед футером он уходит со страницей. Проекты раскрываются как разделы досье, публикации разворачиваются из трех до полного списка. В светлом футере одна отрывная карточка с именем, почтой, телефоном и неподвижным перфорированным корешком. На телефоне используется вертикальная композиция.

Сборка также создает `dist/dossier/index.html`. После нового deploy на Render вариант доступен по `/dossier/`. Переключателей вариантов в интерфейсе нет.

RICS в третьем варианте плавно реагирует на прокрутку. Под портретом SVG-линии вместо арки. Наведение на публикации меняет цвет и подчеркивание, сохраняя размеры текста и положение страницы. Сгиб единой контактной карточки формируется обрезкой листа и отдельной треугольной обратной стороной.
